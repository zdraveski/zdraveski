### Hi, I'm zdraveski

I build free, open-source plugins for [Claude Code](https://claude.com/claude-code): small tools that run on your own computer, need no account, and are tested on Windows, macOS and Linux.

| Project | What it does |
|---|---|
| **[project-memory](https://github.com/zdraveski/project-memory)** · [site](https://zdraveski.github.io/project-memory/) | Claude remembers your work between conversations: where you left off, what was decided, and every earlier version of its notes, so a lost one can come back. |
| **[claude-juice](https://github.com/zdraveski/claude-juice)** · [site](https://zdraveski.github.io/claude-juice/web/) | Your Claude Code usage limits as batteries in the status line: the 5-hour session, the weekly limit and how full the chat is, with a warning before you run out. |

Both are MIT-licensed. Bug reports, ideas and pull requests are welcome in each project's issues.
